## 원문 정합성

웹 제안서는 `../제안서.md`의 내용을 모두 표시합니다. 금액·공수·일정·개발 범위·인수 기준뿐 아니라 환산 단가와 회사 개요의 기준 수치도 원문과 같은 값으로 반영합니다.

원문을 수정할 때에는 웹의 해당 섹션도 함께 수정하고, 최소한 다음 항목을 대조합니다.

- 금액·공수(49,700,000원 / 92,400,000원 / 71 MD / 132 MD / 2.37 MM / 84일 / 1.18명 / 약 118%)와 항목별 견적·대금 합계
- 일정 8단계의 일수·누적·게이트 8회, 화면 18개, 인수 기준 19항목
- 참여 인력 7명의 참여율·MD·MM, 실적 기간, 데이터 구조와 사전 검증 질문 3문항
- 회사 개요와 환산 단가를 포함한 원문의 핵심 문장

제안서의 절 번호는 웹에서 §01~§09로 재배치되어 있으므로, 참조 번호는 화면 구성에 맞춰 표기합니다.
